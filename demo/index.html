Install once, then leave it. The effects switch on by themselves every year from 18 October to 2 November and stay off the rest of the time. There is nothing to remove afterwards. Installed earlier? You will see nothing until 18 October. That is expected, not a bug.

One snippet, library included. Paste it into the footer or custom-code field of your site or builder. That is the whole install.

For projects with a bundler. Three short steps.

1. Install

npm install halloween.js

2. Import it once in your entry file

import "halloween.js";

3. Turn it on

Built to stay out of the way

Safe defaults, so it never gets in a visitor's way.

No layout changes

Ambient effects render in a fixed overlay layer. Nothing else on the page shifts or resizes.

Seasonal by default

Only runs in a window around Halloween, every year, unless you widen or override it.

Accessible motion

Respects prefers-reduced-motion live, without a page reload.
